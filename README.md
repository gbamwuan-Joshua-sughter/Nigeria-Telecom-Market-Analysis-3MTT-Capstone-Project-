# 🇳🇬 Nigeria Telecommunications Market Analysis Dashboard

## 📊 Project Overview

This project presents an interactive **Power BI analysis of Nigeria's telecommunications market** using industry data from the **Nigerian Communications Commission (NCC)**.

The analysis covers the period from **January 2023 to May 2026** and examines subscriber trends, operator market share, Internet data usage, monthly and year-over-year growth, average data usage per subscriber, and the migration across 2G, 3G, 4G and 5G network generations.

The project demonstrates an end-to-end data analytics workflow, from **automated data extraction using Python** through data preparation, modelling, DAX analysis and interactive Power BI dashboard development.

---

## 🎯 Project Objectives

The project aims to:

- Analyse changes in Nigeria's telecommunications subscriber base.
- Examine market-share movements among major network operators.
- Measure monthly and year-over-year subscriber growth.
- Analyse Internet data-usage trends.
- Measure monthly and year-over-year data-usage growth.
- Calculate average monthly data usage per subscriber.
- Analyse the transition from 2G and 3G toward 4G and 5G.
- Build an interactive business intelligence dashboard.
- Extract and prepare telecommunications data programmatically using Python.

📈 Key Findings
Total subscribers declined from 226.23M to 189.68M, approximately 16.2%.
Internet data usage increased from 517.67K TB to 1.50M TB, approximately 190%.
Average data usage per subscriber increased from 2.34GB to 8.12GB.
MTN's market share increased from 40.65% to 51.13%.
Airtel's market share increased from 26.77% to 34.51%.
Globacom declined from 26.67% to 12.37%.
T2 declined from 5.76% to 1.87%.
MTN and Airtel's combined market share increased from 67.42% to 85.64%.
2G and 3G combined share declined from approximately 74.82% to 41.22%.
4G and 5G combined share increased from approximately 25.18% to 58.79%.
Year-over-year data usage growth reached 44.15% in May 2026, with a minimum of 28.25% in April 2025.
💡 Key Insight

The Nigerian telecommunications market became smaller in subscriber numbers but substantially more data-intensive.

The decline in subscribers occurred alongside rapid growth in Internet data consumption and a major migration toward newer network technologies.

⚠️ Data Limitation

The available NCC dataset provides Internet data usage at the overall market level, rather than separate monthly data usage for each operator.

Therefore, the project does not make claims about which individual operator generated the highest data traffic.
